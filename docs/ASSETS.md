## Replacing Assets
1. Place replacement `.jpg` or `.webp` files in `public/assets/` using the exact filenames above, OR update paths in `src/assets/media.js`.
2. Recommended resolution: `1600px` wide for 16:9 hero/banners, `1000px` wide for 4:5 product/ritual cards.

## Fonts & Icons
- **Fonts**: `Cormorant Garamond` (weights 400, 500, 600, 700, italic) and `Inter` (weights 300, 400, 500, 600).
- **Icons**: Lucide React + custom inline botanical SVG line-art icons.
