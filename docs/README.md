# Nature's Golden Gift

> *Nature's purest gold, from farm to kitchen.*

An immersive, editorial e-commerce frontend experience for **Nature's Golden Gift**, a natural Indian turmeric brand blending botanical apothecary luxury, cinematic anime-inspired landscape storytelling, and frictionless modern commerce.

## Project Structure

- `docs/` — Architecture, PRD, design system, rules, roadmap, content, assets, testing, and persistent memory (`MEMORY.md`).
- `src/` — Component-driven React + Vite + Tailwind CSS application.
- `public/assets/` — Centralized visual assets (generated anime-inspired landscapes & editorial product photography).
- `dist/` — Standalone runnable build output.

## Quick Start

```bash
npm install
npm run dev      # Start Vite development server
npm run build    # Build production bundle
npm run preview  # Preview production build
```
